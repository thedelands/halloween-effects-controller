# Code of Conduct

## Our standards

We are committed to a welcoming, respectful, and harassment-free community.
Use inclusive language, accept constructive feedback, and focus discussion on
what is best for the project and its users.

Harassment, personal attacks, discrimination, and the publication of another
person's private information are not acceptable.

## Enforcement

Project maintainers may remove, edit, or reject contributions and comments
that do not align with these standards. Report unacceptable behavior privately
to the project maintainers. Reports will be reviewed promptly and handled as
confidentially as practical.

This code of conduct applies in project spaces and when representing the
project in public spaces.
